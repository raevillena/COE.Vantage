## Gotchas
- Windows: stop the backend before `prisma generate`. Heredocs with quotes break in Git Bash (use the Write tool or a script file). Playwright wipes `tests/e2e/.results/` every run. A foreground command over ~120 s is killed and takes its test worker with it: run long suites in the background. Do not edit sources while tests run. Playwright `locator.waitFor()` has no timeout by default (a test hung for the full test time): pass `{ timeout }`.
- In e2e tests, `main` matches the app's outer `<main>` too: use the `data-testid`s. Pending (cross-department) blocks also carry `data-draggable-block`.
- The public lookup is rate limited (80 requests / 15 min / IP; restart the backend to clear). `tsx` scripts in `backend/scripts` need the college scope (bare `PrismaClient` queries on scoped models fail).
- Naming trap: `College.currentAcademicYearId/currentSemester` and API `isActive`/`currentSemester` are the SCHEDULING semester; the Current Semester is `calendar*` / `isCalendar`.
- Email: `utils/email.ts` has one pooled transport; reserved example domains and `@coe.vantage` are logged, never sent.
